# 📂 Projet : Python - Entrées / Sorties  

Ce dossier contient une série d’exercices pratiques sur la **gestion des fichiers** et la **sérialisation en JSON** avec Python.  
L’objectif est de maîtriser la lecture, l’écriture et la manipulation de données dans des fichiers texte ou JSON, ainsi que l’utilisation des arguments en ligne de commande.  

## 📌 Contenu des exercices  

1. **Lecture de fichier** – lire et afficher le contenu d’un fichier texte.  
2. **Écriture de fichier** – écrire une chaîne dans un fichier (création ou remplacement).  
3. **Ajout dans un fichier** – ajouter du texte à la fin d’un fichier.  
4. **Conversion en JSON** – sérialiser un objet Python en chaîne JSON.  
5. **Conversion depuis JSON** – désérialiser une chaîne JSON en objet Python.  
6. **Sauvegarde en fichier JSON** – écrire un objet en JSON dans un fichier.  
7. **Chargement depuis fichier JSON** – lire un fichier JSON et recréer l’objet Python.  
8. **Script add_item.py** – ajouter les arguments passés en ligne de commande dans une liste sauvegardée en JSON.  
9. **class_to_json** – obtenir la représentation en dictionnaire d’un objet simple.  
10. **Classe Student** – sérialisation et filtrage des attributs en JSON.  
11. **Reload Student** – recharger un objet `Student` à partir d’un dictionnaire JSON.  
12. **Triangle de Pascal** – générer une représentation en liste de listes.  

## ⚙️ Exigences  

- Python **3.8.5** (Ubuntu 20.04 LTS)  
- Respect de la norme **pycodestyle (2.7.\*)**  
- Tous les fichiers doivent être exécutables (`chmod +x`)  
- Tests réalisés avec **doctest**  

---

👉 Ce projet permet de comprendre la **sérialisation/désérialisation**, la gestion des fichiers et d’acquérir de bonnes pratiques avec Python (utilisation de `with`, organisation des scripts, documentation).
