# 🧪 Tests du projet Python - Entrées / Sorties

Ce dossier contient les **fichiers de tests** pour vérifier le bon fonctionnement des exercices.  
Les tests utilisent le module intégré **doctest** de Python.

## 📌 Organisation

- Tous les tests sont placés dans ce dossier `tests/`.  
- Chaque fichier de test a l’extension **.txt**.  
- Les tests suivent les exemples d’utilisation directement dans le code.  

## ▶️ Exécution des tests

Pour exécuter l’ensemble des tests :  

```bash
python3 -m doctest ./tests/*
